🎓 AI FaceID & Voice Attendance System

An intelligent attendance management system powered by Artificial Intelligence, Face Recognition, and Voice Authentication. This platform enables students to join classes using QR codes, enroll in subjects with unique subject codes, and mark attendance seamlessly through AI-based FaceID and voice recognition technology.

✨ Features
🔐 Secure Teacher & Student Authentication
📷 AI-Powered Face Recognition Attendance
🎤 Voice-Based Attendance Verification
📱 QR Code Class Join System
📚 Subject Enrollment with Subject Codes
📊 Smart Dashboard & Attendance Analytics
⚡ Fast, Contactless & Automated Attendance Tracking
🚀 Tech Stack
Python
Streamlit
OpenCV
Dlib / Face Recognition
Supabase
Machine Learning & AI
💡 Project Goal

To modernize traditional attendance systems with a secure, automated, and AI-driven solution for classrooms and institutions.
